# SMART PARKING SIMULATOR
### Project Overview

**1. Introduction**

The Smart Parking Simulator is a software-based parking management system developed to solve the problem of finding available parking spaces in crowded areas. Drivers often waste time and fuel searching for vacant parking slots, especially in busy locations.

Our project aims to make this process easier by providing a digital platform where users can check parking availability, park their vehicles, and release occupied parking spaces efficiently.

**2. Objectives**

The main objectives of our project are:
- To reduce the time spent searching for vacant parking spaces.
- To manage parking slots systematically.
- To provide real-time information about occupied and available slots.
- To maintain vehicle and parking records.
- To make parking management more efficient and user-friendly.

**3. Working of the Simulator**

The simulator provides a graphical user interface (GUI) through which users can interact with the parking system.

The major functionalities include:

- **Park Vehicle:** Allows users to enter their details, including owner name, vehicle number, and vehicle type, and assigns an available parking slot.
- **Release Vehicle:** Allows users to remove their vehicle from the parking area when leaving.
- **Search Vehicle:** Helps locate a vehicle using its vehicle number.
- **Display Parking Slots:** Shows the parking layout and indicates whether individual slots are occupied or vacant.
- **Reset Parking Lot:** Resets the parking system when required.
- **Exit:** Allows users to safely close the application.

**4. Technologies Used**

- **C++:** Used to develop the core parking management logic.
- **Object-Oriented Programming (OOPS):** Used to organize the program through classes and objects.
- **Qt Framework:** Used to develop the graphical user interface.
- **File Handling:** Used to maintain and store parking-related records.

**5. Data Structures and OOPS Concepts**

The project incorporates various programming concepts:

**Data Structures:**
- Arrays: Used for representing parking slots.
- Linked Lists: Used for managing dynamically stored records.
- Queues: Used for handling vehicles waiting for parking.
- Stacks: Used for managing data in a Last-In-First-Out (LIFO) manner.

**OOPS Concepts:**
- Encapsulation: Combines data and related functions into classes.
- Inheritance: Allows one class to acquire properties and functionalities of another class.
- Polymorphism: Allows functions or operations to behave differently depending on the context.
- Constructors and Destructors: Help initialize and manage objects.

**6. Benefits of the Project**

- Saves users' time and effort.
- Reduces unnecessary vehicle movement.
- Makes parking management organized.
- Provides a simple and interactive interface.
- Maintains parking information systematically.
- Demonstrates the practical application of DSA and OOPS concepts.

**7. Conclusion**

The Smart Parking Simulator demonstrates how programming concepts can be applied to solve a real-world problem. By combining C++, Data Structures, OOPS, File Handling, and Qt GUI, we have developed a system that simplifies parking management and improves the overall parking experience.

The project can further be enhanced by integrating sensors, automated payment facilities, and real-time hardware-based parking availability.
